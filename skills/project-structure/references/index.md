# 索引

references/ 的入口。这里说明目录结构与使用顺序；具体规范按文件名在对应目录里找。

## 结构

- 框架规范按语言放子目录（python/、node/…），一个文件一个框架。
- 语言无关的规范放根目录（如 ddd.md）。
- 各语言的选型推荐放对应子目录的 picks.md。

## 使用

1. 技术栈未定时，先读目标语言子目录的 picks.md 确定选型，等用户确认。
2. 按选定框架读对应子目录的规范文件；语言无关的主题读根目录文件。
3. 组合型文件开头列出的相关文件一并读取。

## 扩展

- 新框架：`<框架>.md` 放进对应语言子目录。
- 新语言：建子目录，放 picks.md 和框架文件。

# Skill 通用维护约定

适用于 `skills/` 下所有技能；维护具体 skill 时，再读取对应的专项说明。

## 独立分发

- 每个 skill 目录是独立分发单元。执行所需的规则和随附静态资源放在自身目录中，内部文件引用须在该目录内解析。
- `SKILL.md` 及随附文件不引用仓库外层的 `docs/`、`AGENTS.md` 等维护资源。目标项目的代码、规范和文档仍可作为任务输入。
- 源码维护文档放在仓库 `docs/`，由仓库 `AGENTS.md` 和文档索引引导读取，不从分发目录回链。

新增或移动资源后，检查内部引用是否存在、是否越出分发目录，确认单独分发该目录后仍能定位所需资源。

# Learning

用于隔离尚未固化为 `skills`、`agents` 或 `commands` 的调研与学习笔记。

该目录不参与任何 skill、agent 或 command 的发现与执行。

## 内容范围

- 工具、框架和产品选型；
- 工作流与架构比较；
- 已核验的方法、约束和风险；
- 可进一步提炼为能力的候选实践。

## 约定

- 按主题建立子目录，文件名使用小写短横线。
- 优先引用一手来源，并记录检索日期。
- 区分已核验事实、判断和待验证事项。
- 不在学习笔记中放凭据、真实目标、客户信息或可直接运行的未授权攻击步骤。
- 当结论已经稳定且具备明确输入、输出、约束和验证方式时，再提炼到对应能力目录。
